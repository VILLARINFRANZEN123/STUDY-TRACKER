# Study Tracker App

Frontend-only project built with HTML, CSS, and vanilla JavaScript.

## Features
- Dashboard with progress overview
- Subjects list with add/delete
- Study timer (Pomodoro-style)
- Resources library
- Achievements/stats

## Tech Stack
- HTML, CSS, JavaScript
- LocalStorage for persistence
- Responsive design

## Run
Clone the repo, then open `index.html` in your browser.
